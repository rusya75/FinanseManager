# Менеджер личных финансов

Настольное приложение на Python (tkinter) для учёта доходов и расходов.
Данные хранятся в CSV-файле `data/transactions.csv` (создаётся автоматически).

## Требования
- Python 3.8 или новее (https://www.python.org/downloads/)
- Сторонние библиотеки не нужны: `tkinter`, `csv`, `unittest` входят в стандартную библиотеку.
  (В Windows и macOS `tkinter` ставится вместе с Python. В Linux: `sudo apt install python3-tk`.)

## Запуск
```
python main.py
```

## Запуск тестов
```
python -m unittest -v
```

## Возможности
- добавление, изменение и удаление операций (доход / расход);
- поиск по описанию и категории, фильтр по типу и категории, сортировка по дате и сумме;
- главная панель: баланс, доходы, расходы, последние операции;
- статистика по категориям;
- автоматическое сохранение и загрузка из CSV;
- проверка вводимых данных (сумма, категория, дата, длина описания);
- демо-данные: Настройки → «Загрузить демо-данные».

## Структура проекта
| Файл | Назначение |
|---|---|
| `main.py` | точка входа |
| `app.py` | графический интерфейс (класс `FinanceApp`) |
| `manager.py` | бизнес-логика (класс `FinanceManager`) |
| `models.py` | модели: `Transaction`, `Income`, `Expense`, проверка данных |
| `storage.py` | хранилище: `BaseStorage`, `CsvStorage` |
| `test_finance.py` | автоматические тесты |
| `data/demo_transactions.csv` | демонстрационные данные |
